# 质量管理体系"方针"相关标准条款要点

> 本文件供技能推导时对照，确保方针覆盖标准要求。条款以要点形式呈现，便于理解，非标准原文逐字引用；正式引用请以现行标准文本为准。

## 一、ISO9001:2015 核心条款（本技能主依据）

### 5.1 领导作用与承诺
最高管理者应证明其对质量管理体系的领导作用和承诺，其中包括：
- 确保制定质量方针和质量目标，并与**组织的战略方向和环境相一致**；
- 确保将质量管理体系要求融入组织的业务过程。

### 5.2 质量方针

#### 5.2.1 制定质量方针
最高管理者应建立、实施并保持质量方针，方针应：
- **a) 适应组织的宗旨和环境，包括其战略方向**；
- **b) 为设定质量目标提供框架**；
- **c) 包含满足适用要求的承诺**；
- **d) 包含对持续改进质量管理体系有效性的承诺**。

#### 5.2.2 沟通质量方针
质量方针应：
- 可供获取并保持成文信息；
- 在组织内得到沟通、理解和应用；
- 适宜时可为相关方所获取。

### 6.2 质量目标及其实现的策划
- 组织应在相关职能、层次和过程上建立质量目标；
- 质量目标应**与质量方针保持一致**，可测量，并支持战略方向。

### 9.3 管理评审
- 管理评审的输入应包含质量方针的适宜性审视，确保方针持续适宜、充分、有效。

### 7.3 意识 / 7.4 沟通
- 确保员工知晓质量方针及其与自身工作的相关性（意识）；
- 就质量管理体系有效性进行内部沟通（含方针宣贯）。

## 二、同族标准"方针"条款映射

| 标准 | 方针条款 | 与 ISO9001 的差异要点 |
|------|----------|----------------------|
| IATF16949:2016 | 5.2.1 / 5.2.2 | 与 ISO9001 一致；补充需支持过程有效性和效率 |
| ISO13485:2016 | 5.2 质量方针 | 强调法规要求和医疗器件安全 |
| ISO22000:2018 | 5.2 食品安全方针 | 强调食品安全、合规、沟通 |
| ISO14001:2015 | 5.2 环境方针 | 改为"环境方针"，含环境保护承诺、污染预防 |
| ISO45001:2018 | 5.2 职业健康安全方针 | 改为"职业健康安全方针"，含风险与机遇、 workers 协商 |

> 本技能聚焦 QMS（ISO9001 族）。若用户涉足上述其他体系，按上表替换"方针"对应的体系名称与承诺侧重点即可，推导逻辑不变。

## 三、自检速查（推导后逐条核对）

- [ ] 是否体现"适应战略方向/环境"（5.2.1 a）？
- [ ] 是否为质量目标提供框架（5.2.1 b）？
- [ ] 是否承诺满足适用要求（法规/客户）（5.2.1 c）？
- [ ] 是否承诺持续改进（5.2.1 d）？
- [ ] 是否由最高管理者发布、成文可获取（5.2.2）？
