# 行业方针参考库（八行业范例）

> 仅作"强调点"参考，**禁止照搬文案**。最终每条方针必须回扣用户提供的战略锚点（见 strategy_alignment_checklist.md）。
> 行业不在下表时，用"产品特性 → 客户关切 → 过程风险"三步法推导。

## 1. 汽车零部件
- 强调点：零缺陷思维、PPM 管控、供应链协同、追溯
- 客户承诺锚点：主机厂零返工、准时交付
- 参考 KPI：PPM 值、准时交付率、供应商 PPM

## 2. 医疗器械
- 强调点：法规符合、患者安全、全程追溯
- 客户承诺锚点：不良事件可控、召回响应
- 参考 KPI：不良事件数、召回响应时间、批追溯率

## 3. 电子产品
- 强调点：可靠性、一致性、快速响应
- 客户承诺锚点：首次良率、客诉响应
- 参考 KPI：首次良率、客诉响应时间

## 4. 食品加工
- 强调点：食品安全、HACCP、批次追溯
- 客户承诺锚点：微生物合格、合规
- 参考 KPI：微生物合格率、HACCP 执行率

## 5. 软件 / IT
- 强调点：可用性、安全性、客户交付
- 客户承诺锚点：系统可用率、漏洞修复
- 参考 KPI：系统可用率、漏洞修复时效

## 6. 化工 / 原材料
- 强调点：过程控制、批次一致性、安全环保
- 客户承诺锚点：一次合格率、安全事故为零
- 参考 KPI：一次合格率、安全事故数

## 7. 服务业（通用，扩容）
- 强调点：响应时效、服务一致性、客户满意
- 客户承诺锚点：首响时间、满意度
- 参考 KPI：首次响应时长、NPS / 满意度

## 8. 建筑 / 工程（扩容）
- 强调点：工期、安全、合规交付
- 客户承诺锚点：零事故、按期交付
- 参考 KPI：百万工时伤害率、工期达成率

## 通用兜底推导法（不在上述行业时）
1. 产品/服务最关键的**特性**是什么？（→ 过程承诺）
2. 客户最在意的**关切**是什么？（→ 对客户承诺）
3. 最致命的**过程/合规风险**是什么？（→ 改进承诺）
4. 公司未来 3–5 年**战略方向**？（→ 发展承诺）
将四个答案各凝练为一条方针，即构成方针草案。
